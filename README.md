# RC Estética Regenerativa — Sistema

Aplicação estática em HTML/JS/CSS com persistência em Supabase.

## Configuração

1. Edite o arquivo `config.js` e substitua os placeholders pela URL e anon key reais do Supabase.
2. Ajuste o arquivo `vercel.json` para o ambiente de deploy se necessário.
3. Faça o deploy na Vercel.

## Variáveis relevantes

- `window.RC_CONFIG.SUPABASE_URL`
- `window.RC_CONFIG.SUPABASE_ANON_KEY`

## Public access

A aplicação é uma SPA estática e pode ser hospedada na Vercel com acesso público.
